Agent Skill

Ship reliable Robot Framework tests faster.

This skill generates consistent, maintainable Robot Framework suites for Python-centric API and service testing. It enforces valid syntax, reusable structure, and deterministic assertions so teams avoid fragile test code.

Install with Skills CLI

npx skills add https://github.com/arvind3/robot-framework-py-skill --skill robot-framework-py

Use with Codex and compatible SKILL.md runtimes.

Value it brings

Consistency by default

Produces valid Robot Framework sections and structures tests into suites, resources, libraries, and variables folders.

API-first productivity

Optimized for RequestsLibrary patterns including session reuse, reusable headers, and status plus payload assertions.

Lower review overhead

Enforces deterministic assertions and anti-hallucination guidance, reducing cleanup cycles during code reviews.

Example 2: Python keyword library

Prompt

Create a class-based custom keyword library with
Add Integers and Multiply Integers.

Output style

from robot.api.deco import keyword

class MathKeywords:
    @keyword("Add Integers")
    def add_integers(self, left: int, right: int) -> int:
        return int(left) + int(right)

    @keyword("Multiply Integers")
    def multiply_integers(self, left: int, right: int) -> int:
        return int(left) * int(right)
